02 · KICK CAN 팀 4인 · 개인 담당 Node 2

CAN 기반 RC카의 계기판 노드

STM32 노드가 CAN으로 연결된 RC카에서 계기판 노드를 맡아, 차량 상태 표시와 출력 제어를 구현했습니다.

개인 담당 · Node 2

차량 상태를 TFT와 CLCD에 표시

방향지시등, 조명, 부저 출력 제어

팀 내 역할 분담

Controller입력과 RFID 인증팀원
Main Node모터 구동과 중계팀원
Node 1온도 · 초음파 · 조도 센싱팀원
Node 2계기판 표시와 출력 제어최세은

CAN 수신 검증과 상태 기반 출력

01

수신과 검증

프레임 큐에서 ID · 형식 · 길이를 확인

02

상태 반영

명령을 해석해 계기판 상태 모델 갱신

03

화면과 장치 출력

TFT 2대, CLCD, 조명과 부저 제어

하드웨어

NUCLEO-F103RB · 내부 CAN 500kbps · SPI 공유 버스

발표 버전은 내부 CAN이 없는 F411RE라 MCP2515 외장 컨트롤러를 SPI에 붙여 썼고, 이후 내부 CAN을 가진 F103으로 옮기며 외장 칩을 제거했습니다.
